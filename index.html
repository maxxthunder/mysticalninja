About this generator

Logbook passwords for The Legend of the Mystical Ninja (Konami, 1992; Ganbare Goemon: Yukihime Kyūshutsu Emaki in Japan). The algorithm was taken from the game's own code. A full logbook (31 symbols, 55 for two players) holds everything below; a short one (6 or 7 symbols) holds the zone and the four jutsu, but the game clears the jutsu as the zone starts, so only the zone counts.

The US, European and German releases (and the US Virtual Console version) use the same code, so a logbook works in all of them. German menus say WEITER, then VON LOGBUCHEINTRAG. The Japanese release writes the same logbooks in kana: pick Japan 1.1–1.2 or Japan 1.0 under Game version (1.0 scrambles some symbols differently). In Japanese, the entry screen is つづきをあそぶ, then たびにっきを つけたところから.

To use one: on the title screen choose CONTINUE, then FROM LOGBOOK ENTRY. B types a symbol, Y deletes. Move to END and press B.

If a logbook won't work:

  • Upper and lower case are different symbols: K and k, W and w are not the same.
  • There's no O and no I. An o is almost always the zero; an I is usually a lower-case l. The decoder suggests one-symbol fixes.
  • △ and ♡ are easy to swap when copying from text that has neither.

How the password is built

Each symbol is a 6-bit number; the 64 symbols in order are . The first symbol holds the data length and the second a random key. Then come the data symbols and two checksum symbols, each one XORed with a fixed table and shifted by the key. The checksum is the sum of every field, masked to two 6-bit values. Fields are packed lowest bit first, six bits to a symbol, and each block (the shared fields, then each player) starts on a new symbol. The game only accepts 6, 7, 31 or 55 symbols, a zone below 10 and a story step below 8; nothing else is range-checked. Code: decode $1C:AFC7, encode $1C:ACE5, tables at $02:FD3E.
